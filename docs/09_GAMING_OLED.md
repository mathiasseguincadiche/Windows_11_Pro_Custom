# Gaming et OLED

## Intel Arc B580

Contrôler Resizable BAR et Above 4G Decoding dans l'UEFI puis valider le pilote Intel Arc sous Windows.

## ROG Strix OLED XG27AQDMES

- vérifier 2560×1440 à 240 Hz ;
- vérifier VRR/Adaptive Sync selon le pilote et le jeu ;
- configurer HDR avec l'outil Windows approprié si HDR est utilisé ;
- conserver les fonctions de protection OLED du moniteur ;
- éviter un bureau statique lumineux pendant de très longues périodes ;
- le masquage automatique de la barre des tâches reste optionnel.

Les réglages gaming ne doivent jamais désactiver les composants nécessaires à WSL2.
