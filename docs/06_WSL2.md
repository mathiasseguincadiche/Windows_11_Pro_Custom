# WSL2

## Profil principal

```ini
[wsl2]
memory=16GB
processors=6
swap=8GB
networkingMode=mirrored
dnsTunneling=true
firewall=true
autoProxy=true

[experimental]
autoMemoryReclaim=gradual
sparseVhd=true
```

Le profil est installé dans `%UserProfile%\.wslconfig`.

## Profils disponibles

- `standard.wslconfig` : usage quotidien.
- `lab-heavy.wslconfig` : labs Kubernetes plus lourds.
- `nat-fallback.wslconfig` : secours si un VPN ou un environnement particulier pose problème en mode mirrored.

Après un changement :

```powershell
wsl --shutdown
```

## Emplacement

Ubuntu est installé sous :

```text
D:\WSL\Ubuntu-DevOps
```

Le volume `D:` reste NTFS.

## Linux

Le fichier `/etc/wsl.conf` active systemd et conserve l'interop Windows.
