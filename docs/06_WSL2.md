# WSL2

## Objectif

WSL2 fournit l'environnement Linux principal du poste DevOps sans dual boot et sans partition EXT4 physique.

Architecture :

```text
Windows 11 Pro
└── D:\WSL\Ubuntu-DevOps\ext4.vhdx
    └── Ubuntu / ext4
        └── /home/<user>/projects
```

Les projets utilisés avec Docker, Terraform, Ansible, kubectl et Helm restent dans le système de fichiers Linux, pas sous `/mnt/c` ou `/mnt/d`.

## Profil principal

```ini
[wsl2]
memory=16GB
processors=6
swap=8GB
networkingMode=mirrored
dnsTunneling=true
firewall=true
autoProxy=true

[experimental]
autoMemoryReclaim=gradual
sparseVhd=true
```

Le profil est installé dans :

```text
%UserProfile%\.wslconfig
```

## Profils disponibles

- `standard.wslconfig` : 6 CPU, 16 Go RAM, 8 Go swap, usage quotidien ;
- `lab-heavy.wslconfig` : 10 CPU, 24 Go RAM, 12 Go swap, labs Kubernetes lourds ;
- `nat-fallback.wslconfig` : profil de secours réseau en NAT.

Après une modification de `.wslconfig` :

```powershell
wsl --shutdown
```

## Emplacement

Ubuntu est installé sous :

```text
D:\WSL\Ubuntu-DevOps
```

Le volume `D:` reste NTFS. L'EXT4 existe uniquement dans le VHDX WSL2.

## Linux

Le fichier :

```text
/etc/wsl.conf
```

configure la distribution Ubuntu. Le dépôt y active systemd et conserve l'interop Windows.

## Vérifications rapides

PowerShell :

```powershell
wsl --version
wsl --status
wsl -l -v
```

Ubuntu :

```bash
whoami
echo "$HOME"
uname -a
free -h
df -h /
systemctl status --no-pager
```

Qualification DevOps complète :

```powershell
.\install.ps1 -Mode Verify -ValidateDevOps
```
